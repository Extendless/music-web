## applemusic-to-obsidian
A Python script that will convert apple music library export XML files to MD files to be displayed in obsidian

# Usage
## For Apple Music
- Open Apple Music, go to the tab bar, and select: File > Library > Export Library
- Place the "XML-MD" file and your Library.xml in the same folder
- Run the script
